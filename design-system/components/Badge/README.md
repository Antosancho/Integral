# Badge

Etiqueta de estado, píldora de 24px. Siempre ícono + palabra (nunca solo color).

`ig-badge-danger` stock negativo, vencido · `ig-badge-warning` stock bajo, merma · `ig-badge-success` pagada, reposición confirmada · `ig-badge-info` vence hoy, informativo · `ig-badge-neutral` tipo de movimiento, categoría.
