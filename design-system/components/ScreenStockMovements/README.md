# ScreenStockMovements

Historial de **movimientos de stock** (MVP), segmentado "Movimientos" dentro de Stock. También se abre filtrado desde el menú ⋮ de una fila ("Ver movimientos").

- Columnas: Fecha · Tipo (badge: Venta neutral, Reposición success, Merma warning, Alta inicial info) · Producto · Cantidad (+ verde / − ; mermas en warning) · Stock resultante (negativo en danger) · Detalle (n° de venta clickeable → Historial de ventas; notas; vencimiento del lote).
- Filtros: producto, tipo (segmentado), período (default: últimos 7 días).
- Solo lectura. Orden: más reciente primero.
