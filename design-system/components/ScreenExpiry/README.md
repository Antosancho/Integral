# ScreenExpiry

Al abrir la app (en Stock), si hay lotes vencidos o que vencen hoy, el widget aparece en el header. El popup **no** se abre solo: el widget es suficientemente visible y no interrumpe (principio: las alertas informan, no bloquean). Propuesta opcional: el widget hace un pulso suave 2 veces al iniciar.

Ver `ExpiryAlert` para el detalle de filas y acciones. Un mismo producto puede aparecer en ambos grupos si tiene lotes distintos.
