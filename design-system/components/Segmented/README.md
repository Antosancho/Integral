# Segmented

Control segmentado para cambiar vista dentro de una pantalla (sin sub-rutas).

Usos: período de Estadísticas (Hoy · Esta semana · **Este mes** · Personalizado), Ventas (**Nueva venta** · Historial), Stock (**Productos** · Movimientos), tabs "Por hora / Por día de semana". ←/→ mueve la selección; el seleccionado es `surface` con `shadow-sm` sobre `surface-sunken`.
