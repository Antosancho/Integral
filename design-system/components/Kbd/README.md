# Kbd

Chip de tecla. Enseña los atajos en contexto sin tutoriales: el cajero aprende viendo.

- Mostrar en: barra de atajos bajo el input de código (Ventas), pie de cada modal y popup, botones con atajo.
- Nombres de tecla en español de teclado: **Supr** (Delete), **Enter**, **Esc**, **Ctrl**, **F2**, **F10**, flechas ↑ ↓.
- Fila de atajos: `ig-shortcuts` — cada ítem `Kbd + texto` en `caption`, color `ink-muted`.
- Sobre `primary`, el chip se invierte automáticamente (borde blanco translúcido).
