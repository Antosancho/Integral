# Ranking

Lista ordenada para los top de Estadísticas. Posición en `display` 800 `ink-subtle`, nombre, valor a la derecha (tabular), barra de 6px `chart-2` proporcional al primero.

Usos: Más vendidos (unidades, "412 u."), Más facturan (monto "$ 1.234,50"). Menor rotación usa `Table` (10 filas, con "Última venta" y unidades) en vez de barras.
